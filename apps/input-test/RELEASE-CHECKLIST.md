# Release checks

- [x] Tested v1.1.0 console payload preserved.
- [x] Hardware compatibility/validation scope documented without private captures.
- [x] Public instructions require a console address and explicit USB serial port.
- [x] Source/payload, model/view/lifecycle/browser and host-transport tests.
- [x] Original MIT and third-party font/loader notices retained.
- [x] Reports, local configuration, credentials, ROMs, saves and firmware binaries excluded.
- [x] Source ZIP uses an explicit file allowlist and checksums.

The repository's publication checks run before commit/push. Do not add private local report files to a release.
