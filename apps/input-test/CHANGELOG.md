# Changelog

## 1.1.0

- Keeps the large flat interface and removes the header icon.
- Places Left/Right/Both rumble directly on Motion, with touch and L/R/A release controls.
- Numbers fingers from 1 while preserving surviving labels and raw native IDs.
- Uses solid filled letter outlines to bypass native text shading.
- Includes self-contained TCP/USB launchers, compatibility guards, bounded local reports, tests and licensed font data.

The console payload is byte-identical to the tested build. Repository packaging uses generic instructions and explicit connection arguments; no personal target or serial-port default is included.
